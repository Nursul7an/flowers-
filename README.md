# Пионы для Дарии 🌸

Одностраничный статичный сайт-подарок — маленький мультфильм на ~25 секунд:

1. **Фудзияма на закате** — небо со звёздами, солнце с лучами, снежная шапка, облака, озеро с отражением, цветущая сакура. Камера медленно наезжает.
2. **Восхождение** — девушка-хайкер (кепка, рюкзак, треккинговая палка) поднимается по серпантину, камера следует за ней.
3. **Вершина** — розовый флаг с сердцем, руки вверх, салют (в том числе в форме сердца), конфетти, «Вершина покорена!».
4. **Цветы** — камера отъезжает, на фоне Фудзи распускается букет из 10 махровых пионов в упаковке: «Каждая вершина тебе по силам. А эти цветы — для тебя, Дария». «↻ ещё раз» проигрывает всю историю заново.

Без backend и без сборки.

## Структура

| Файл | Что внутри |
|------|-----------|
| `index.html` | разметка, OG-превью, `noindex`, fallback без JS |
| `css/style.css` | палитра «Вечерний сад», адаптив, reduced-motion |
| `js/main.js` | **`CONFIG`** (тексты, имя, тайминги, цвета, цветы, музыка) + оркестрация сцен на GSAP |
| `js/world.js` | Фудзияма, сакура, озеро, девушка-хайкер (анимация шага), флаг, виртуальная камера |
| `js/peony.js` | SVG-пион «бомба» (наружные лепестки + купол из волнистых чашевидных лепестков), упаковочная бумага, листья, лента, таймлайн распускания |
| `js/particles.js` | Canvas 2D: огоньки, лепестки, тап-взрыв, салют (пион, ива, сердце), конфетти; пулы частиц и адаптивное качество |
| `js/music.js` | мелодия «музыкальной шкатулки» на Web Audio (0 KB), или свой `.mp3` |
| `js/vendor/gsap.min.js` | GSAP 3.15 (бесплатная Standard License) — локальная копия, без CDN |
| `assets/og.jpg` | превью 1200×630 для Telegram / WhatsApp |
| `assets/bouquet.svg` | статичный букет для режима без JS / при ошибке |
| `tools/render-assets.mjs` | перегенерация `og.jpg` и `bouquet.svg` через Playwright |

Вес страницы без шрифтов ≈ 130 KB.

## Запуск локально

```bash
npx http-server -p 8080 .
# http://localhost:8080          — полный сценарий
# http://localhost:8080/?poster  — сразу финальный кадр
```

## Как поменять текст / цвета

Всё в объекте `CONFIG` в начале `js/main.js`: `congrats` (надписи на вершине), `lead`, `dedication`, `name`, `replay`, `summitHeight`, тайминги (`timing.climb` — длительность подъёма), палитры пионов, позиции цветов. Свой трек: положите `assets/music.mp3` (royalty-free) и укажите `music.src: 'assets/music.mp3'`. Чтобы музыка включалась вместе с букетом — `music.startWithBouquet: true`.

После изменения цветов перегенерируйте превью и fallback:

```bash
npx http-server -p 8080 . &
node tools/render-assets.mjs
```

## Деплой на Vercel

После изменения CSS/JS увеличьте номер `?v=` у подключений в `index.html` — так браузеры гарантированно возьмут новые файлы, а не старые из кэша.

1. vercel.com → **Add New Project** → импортировать этот репозиторий. Framework: **Other**, build command пустой, output — корень.
2. После деплоя замените в `index.html` относительный `og:image` на абсолютный: `https://<ваш-домен>.vercel.app/assets/og.jpg` (WhatsApp и Facebook требуют абсолютный URL) и добавьте `<meta property="og:url" content="https://<ваш-домен>.vercel.app/">`.
3. Проверить превью: отправить ссылку себе в Telegram (кэш превью сбрасывается через @WebpageBot).

`noindex` задан и мета-тегом, и заголовком `X-Robots-Tag` в `vercel.json`, плюс `robots.txt`.

## Что реализовано по ТЗ

- Музыка включена сразу; если браузер блокирует звук до касания (телефоны), сцена ждёт за кнопкой «🌸 Начать», и история с музыкой стартуют вместе. История идёт сама: Фудзи → восхождение → салют и поздравление → букет и текст. Финальный текст пишется по буквам, имя светится и переливается золотом, послойное распускание пионов, летящие лепестки (пул, без накопления), тап = 8–15 лепестков, «↻ ещё раз» без перезагрузки, кнопка 🔊/🔇 выключает и включает музыку, OG-превью.
- Edge cases: ожидание шрифтов с таймаутом 2 с, защита от двойного клика, пересчёт раскладки при resize/повороте (отдельный ландшафтный режим), адаптивное число частиц, пауза во фоновой вкладке без рывка, `prefers-reduced-motion` (fade вместо роста), статичная версия без JS или при ошибке загрузки GSAP.

## Открытые вопросы из ТЗ

Формулировка посвящения, цвет пионов, трек и домен — сейчас стоят значения по умолчанию из ТЗ, меняются в `CONFIG`.
